# Group By
df.groupby()
df_test = df[["drive-wheels", "body-style", "price"]]
df_grp = df_test.group_by(["drive-wheels", "body-style"], as_index = False).mean()
** To vizualize this df_grp we can use Pivot()
df_pivot = df_grp.pivot(index = "drive-wheels", columns = "body-style")
** Another one is Heatmap
plt.pcolor(df_pivot, cmap = "RdBu")
plt.colorbar()
plt.show()

# Correlation Statictics
1. Pearson Correlation
    a. Correlation coefficient -
        i.      close to +1: Large positive relationship
        ii.     close to -1: Large Negative relationship
        iii.    close to 0: No relationship
    b. P value -
        i.      P-value < 0.001 Strong certainty in the result
        ii.     P-value < 0.05 Moderate certainty in the result
        iii.    P-value < 0.1 Weak certainty in the result
        iv.     P-value > 0.1 No certainty in the result

    (*) To check if the data is in Strong Correlation -
        i.      Correlation coefficient close to 1 or -1
        ii.     P-value less than 0.001
